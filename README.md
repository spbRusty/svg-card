# WASTELAND — SVG Card Archive

Статическая галерея из 100 оригинальных векторных карточек в сеттинге овощного киберпанка и постапокалипсиса.

- 10 персонажей × 10 боевых сцен.
- Каждая карта — отдельный SVG в `assets/`.
- Скачивание SVG-оригинала и PNG 1024×1440.
- Поиск, фильтры, адаптивная сетка.
- Без внешних библиотек и внешних графических ресурсов.

# WASTELAND — SVG character cards

10 отдельных векторных иллюстраций в формате SVG, размер каждой — 480 × 640.

- Персонажи и предметы визуально различаются.
- На самих изображениях нет описаний, характеристик и подписей.
- Галерея показывает только изображения и ссылки на SVG.
- SVG открываются в браузере и редакторах векторной графики.

GitHub Pages публикует сайт автоматически из ветки `main`.
